# SmartMess

Hostel Mess & Tiffin Management Platform

## About

SmartMess is a full-stack web application designed to simplify
hostel mess and tiffin management for students, mess providers,
and administrators.

## Problem

Managing meal subscriptions, menus, payments, attendance,
and student information manually can be difficult and time-consuming.

## Main Users

- Student
- Mess / Tiffin Provider
- Administrator

## Planned Features

- User authentication
- Student dashboard
- Mess provider dashboard
- Menu management
- Meal subscription
- Meal attendance
- Payment management
- Notifications
- Admin management
- Reports and analytics
